## Projeto em producao

### BNBPlaza - Sistema de Gestao Imobiliaria

Sistema completo para centralizar operacoes imobiliarias, substituindo processos manuais por uma plataforma digital integrada.

**Principais recursos**

- Dashboard financeiro com metricas operacionais
- Gestao de propriedades, ocupacoes e hospedes
- Calculo automatico de receitas e comissoes
- Relatorios mensais em PDF
- Arquitetura offline-first com sincronizacao de dados
