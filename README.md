## 🧠 Sobre Mim

Desenvolvedor Front-End apaixonado por transformar ideias em aplicações web reais. Utilizo **React** e **TypeScript** como base para criar dashboards, sistemas de agendamento, plataformas de autenticação e experiências digitais que funcionam de verdade.

Meu foco está em **performance**, **usabilidade** e **código limpo** — sempre integrando com **Supabase**, **Firebase** e APIs modernas.

Atualmente, trabalho desenvolvendo soluções web personalizadas para negócios na América Latina, com suporte multilíngue (PT/ES/EN) e design focado em conversão.
